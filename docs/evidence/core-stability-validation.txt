Reproduced local defects and fixes
- FAIL before fix: npm run test:e2e 127/128, one failure at tests/e2e/auth.spec.ts:112. Cross-origin POST /api/media/access expected 403 but the documented route did not exist, so Next.js returned a 404 HTML page. Fix: added app/api/media/access/route.ts with same-origin JSON enforcement, no-store responses, 403 cross-origin, 415 non-JSON, 400 malformed JSON and a cache-disabled 404 for no signed URL. privateVideoUrl() still requires a confirmed workspace and workspace-prefixed videos row; the unconfigured local build never returns a demo signed URL.
- Signup root cause from official Supabase signUp behavior: with Confirm email enabled, an already-registered address returns an obfuscated user with empty identities instead of an error. The old signUp() treated that as success and redirected to /auth/verify-email where no code arrives. Fix: lib/auth/errors.ts signupVerificationState() detects empty identities, a missing confirmation timestamp and an unexpected session; signUp() now returns a safe duplicate/no-code message without creating a session or bypassing verification.
- Generic auth failures: lib/auth/errors.ts authFailure() maps documented rate-limit, expired-code, duplicate, weak-password, invalid-credential, disabled-signup, invalid-email, captcha, validation and session-expired codes to useful, non-enumerating copy. Raw provider/SMTP/token details, stack traces and status numbers are never returned.
